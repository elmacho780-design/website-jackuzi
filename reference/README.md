# reference/

Everything the project produced or was given, other than the slides themselves. Start with `../HANDOFF.md`.

| File | What | Use it for |
|---|---|---|
| `HML_Lesson_Library.xlsx` | All 690 lessons (code, strand, level, title, what it teaches, quiz components, programmes), 12 strands, 10 programmes, 12 quiz components, programme map, release plan, routes with positions, entry points by placement band | Looking up any lesson before making it; answering questions about the site structure |
| `HML_Content_Architecture.md` | The reasoning: library plus programme routes, what the developer's chart was missing, quiz components, release order, levels inside a programme, open decisions | Understanding why things are the way they are |
| `HML_Below_Video_Content_L1-10.xlsx` | Notes, practice, check banks, unit tests, skill tags, question types, interface text for lessons 1 to 10 | The model for below-video content of new lessons |
| `below-video-spec.md` | The format and rules from that workbook, written out | Making below-video content for lessons 11 onwards |
| `teaching-guide/presenter-guide-voiceover.md` | Batu's teaching guide: slide sequence, teaching principles, voiceover rules, recording rules, and slide-by-slide Say lines for lessons 1 to 10 | Writing the voiceover and teaching notes for new lessons |
| `teaching-guide/slide-text-lessons-1-10.md` | The source text for every slide of lessons 1 to 10 | The shape to follow when drafting a new lesson; checking slide wording |
| `source-materials/developer-reference-chart.png` | The web developer's first sketch of the course (four tracks) | Context only; the library replaced it |
| `source-materials/hml-logo-original.png` | The original logo file | Making new logo versions (the cleaned ones are in `../assets/`) |
| `source-materials/writing-handouts/` | Six HML academic-writing handouts (fallacies, counterclaims, thesis statements, arguments and bias, quotations, concession) | The Academic and argumentative writing (AW) strand |
| `superseded/` | The Canva master prompt and the old Kimi and Canva decks | History only. Do not follow their design. |
